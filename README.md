# Smart Snippet

App interna de Quipu Advisors para revisar y calificar los proyectos de ley del monitoreo
legislativo diario. Reemplaza al Daily Legal Snippet por correo por una lista limpia y escaneable.

- **App en vivo:** https://camila509.github.io/Snippet-digital/
- **Cómo está hecha, cómo editarla y dónde tocar cada cosa:** ver **[CLAUDE.md](CLAUDE.md)**.

Es un único `index.html` (HTML/CSS/JS, sin build) sobre Supabase + GitHub Pages. Para ajustarlo,
abrí la carpeta en **Claude Code** y pedí el cambio en lenguaje natural, o editá `index.html`
directo desde GitHub (lápiz → commit; se publica solo en ~1 min).
